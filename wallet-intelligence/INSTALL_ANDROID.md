# Install AURA Wallet Intelligence on Android

1. Open https://aura-wallet-intelligence.onrender.com in Chrome.
2. Open Chrome's three-dot menu.
3. Choose **Install app** or **Add to Home screen** and confirm.
4. Open the AURA icon from your home screen.

## First use
- Add a **public Solana address only**.
- Use **Refresh selected** to retrieve balances and recent activity.
- Use **Copy AI context** to paste a source-stamped snapshot into a ChatGPT conversation.
- Export an encrypted backup after adding wallets or refreshing them. Keep the file and passphrase separately.

## Important
- Never enter a seed phrase, private key, recovery phrase or exchange secret.
- Local IndexedDB records are not app-encrypted; protect your Android lock screen and Chrome profile.
- Refresh sends the public address to the public Solana RPC endpoint. The provider can see the address and request metadata.
- This version cannot sign, buy, sell, withdraw or automatically execute transactions.
- A stale local snapshot is not live market data. Public RPC can rate-limit or fail.
